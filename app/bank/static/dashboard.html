HAProxy sits in front of the databases. It sends every write to the primary and spreads reads across the replicas, so no single node does all the work.

  3. Point at the bars: reads are split between the replicas, writes all land on the primary.

If a branch's primary crashes, Patroni notices (via etcd) and automatically promotes a replica. If the coordinator leader crashes, the standby coordinators elect a new leader the same way. Nobody has to step in.

  1. Choose a branch.
  2. …
    docker kill …
    …or simply turn off that laptop's Wi-Fi.
  3. Watch the right side and the cluster cards above: the old primary turns red, and within about 20 seconds another node becomes primary.
  4. Bring the old node back. It rejoins as a replica and catches up on its own:
    docker start …

Customers never connect to a database directly. They go through the coordinator and HAProxy, so the bank keeps serving while nodes fail.

  1. Start simulated customers: one balance check and one small transfer every second.
  2. Now kill a primary (tab 4). Traffic keeps running while you switch tabs.
  3. Point at the strips: reads stay green (replicas keep answering). Writes pause a few seconds during the election, then turn green again.

The coordinator writes every decision to a durable, replicated log before acting. If it crashes halfway through a transfer, the newly elected coordinator reads that log and finishes or undoes the transfer, so money is never lost.

  1. Choose where the coordinator should crash:
  2. Send ₹500 from A-1001 to B-1001 and crash.
    The coordinator turns red, and a transfer is stuck “in doubt” with its rows locked.
  3. Wait about 10 seconds. A standby coordinator on another laptop wins the election, reads the shared log and resolves the transfer: in doubt goes back to 0 and the total returns to ₹22,00,000.
    Only one coordinator running? Then nobody can take over: restart it yourself and it recovers on startup.
  4. Restart the crashed coordinator. It rejoins as a standby:
    docker start coordinator
